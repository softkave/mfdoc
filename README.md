# mfdoc

Monorepo for **mfdoc** — a CLI that generates JS SDKs and HTTP API documentation from your codebase.

## Packages

- [`mfdoc`](./mfdoc) — main CLI and library
- [`sdk-base`](./sdk-base) — shared JS SDK base
- [`examples`](./examples) — usage examples

See [`mfdoc/README.md`](./mfdoc/README.md) for install and CLI docs.
